Esta atividade consiste em criar um modelo de documento de requisitos que contenha seções que  contemplem os tipos de requisitos: funcionais, requisitos não funcionais e requisitos de negócios, além de conter campos para os atributos (definir quais atributos devem ser considerados).

O formato para especificação de requisitos é livre ( textuais,  gráficos, casos de uso, user stories, etc). O importante é deixar claro qual o formato e que tipo de dados devem ser considerados na especificação dos requisitos.
